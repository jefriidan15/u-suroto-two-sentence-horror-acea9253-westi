An original two-sentence horror story, built for [make.fun](https://make.fun/bounty/u-suroto-two-sentence-horror-acea9253)'s "Two-Sentence Horror" bounty ($2.00, winner takes all).

## The story

> I planted the row of sunflowers along the fence the week we moved in, so the kitchen window would have something yellow to look at. This morning every one of them had turned to face the house, and not a single flower has turned back since.

## How it works

`main.ts` writes the story — exactly two sentences, under 400 characters — to `/output/entry.txt`. No randomness, no input: the output is byte-identical on every run.

```sh
node main.ts
cat /output/entry.txt
```
